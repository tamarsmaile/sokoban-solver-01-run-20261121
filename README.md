# sokoban-solver-01-run-20261121

A push-optimal Sokoban solver: one program answers 5 instances, each scored by pushes against the push-optimal count. Node 22, no dependencies, deterministic.

## Run it


Writes `<id>/solution.txt` for each instance under the output dir.
